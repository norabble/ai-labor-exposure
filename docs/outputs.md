# Outputs Reference

**When adding a new pipeline output (CSV, visualization, or printed table), add a row here in the commit that creates it.** This is the authoritative record of what the pipeline produces and what each output is for. If an output changes behaviour or is removed, update or delete its row.

Rows describe what an output is and how to read it. Measured results (r, p, medians, counts) live in `docs/framework.md` and `docs/charts/*.md`, and each row points to where they are, so a pipeline re-run never leaves a stale figure here.

Also carries a `model == "employment_size_benchmark"` row set (`measure == "share"` only, same columns) — a group's observed displacement share correlated against its plain employment share alone, no model score involved. Interpretation leads with the size-free rate measure, printed and read before the share headline, because the share result is mostly this group-size effect.
